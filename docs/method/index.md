The ideas PONZI is built on, whichever package implements them.

- [Stages](stages.md): the replaceable units of a workflow.
- [Content ids and reuse](../using/content-ids.md): identity, and why the same work is never done twice.
- [Provenance (manifests)](../using/manifests.md): the readable provenance of an output.
- [Watched areas](../using/watched-areas.md) (under construction): areas of Major TOM tiles, their tags and span, what a daily look computes.
- [Data sources and catalogs](data-sources.md): where every input comes from and how the catalogs are built.
- [Specs and the PONZI home](../service/configuration.md): the one folder everything is kept in, and how specs build on each other.
