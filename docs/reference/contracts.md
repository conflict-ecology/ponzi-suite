# Store contracts

Every store that crosses a stage boundary has a written contract in ponzi-core (`docs/contracts/`): its arrays, dtypes, fills, chunks, attrs and invariants, and the functions that open, write and validate it.

The contracts below are rendered from ponzi-core at build time, so this page and ponzi-core's code change together. Each page is the contract as ponzi-core holds it; links into ponzi-core's code open on GitHub.
