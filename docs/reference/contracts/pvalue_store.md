# C22: p-value store

**Purpose.** The calibrated scores of one run under one calibration. **Producer:** `ponzi.calibration.write_pvalues` (`ponzi pvalues RUN_DIR --calibration FILE [--overwrite] [--allow-library-mismatch]`; the ponzi-worker stage `pvalues`, collection `ponzi-pvalues`). **Consumers:** `ponzi.products` (`detect`, `detect_path`, `tile_path`: `ponzi detect`, `ponzi detect-path`, `ponzi tile` and the worker stages `detect` and `tile`), which read `anomaly` (and, for a provisional detection spec, `anomaly_staged`) through `open_pvalue_store`, the grid and `epsg` (C25). **Location:** `<run folder>/pvalues_<calibration id>.zarr` (`pvalue_store_name`); the worker writes it through a folder of links to the run's files and keeps it as its own entry, `{PONZI home}/cache/ponzi-pvalues/<content id>/pvalues_<calibration id>.zarr`, and the readers see it beside the run's files again through such a folder.

| Array | Dims | Stored | Read as |
| --- | --- | --- | --- |
| `anomaly` | time, y, x | uint8, chunks (1, Y, X), fill 255 | `-log10 p` of the anomaly score; NaN = no score |
| `ceiling` | time, y, x | same | `-log10 p` of the ceiling score, the largest the anomaly could reach |
| `time`, `y`, `x`, `process_pixels` | | copied from the score store (values, attrs, dims) | |

Packing: stored = `round(20 * -log10 p)`, attrs `scale_factor = 0.05`, `_FillValue = 255`, `units` `1`, `long_name`, `packing`. So 3.0 is 1 in 1,000, at 0.05 decades per step, up to 12.7.

Group attrs: the score store's attrs; `calibration` {model_id, calibration_id, panel_id, kind, n_null, scoring_spec_hash}; `t_lo`, `t_hi` (anchors outside hold no score); `library_check` (CR-020: `calibration_version`, `run_version`, `calibration_major`, `run_major`, `result` `match`, `unknown` or `mismatch allowed`, and `allow_library_mismatch`); `complete` (False until the last write, then True; the metadata is consolidated then).

Invariants: one calibration per store; the calibration's scoring spec hash equals the run's; the calibration's library version (`provenance.ponzi_version`) has the major of the run's (`run_meta.ponzi_version`; SemVer: the first number from 1 on, `0.y` below), unless written with `--allow-library-mismatch`, and a side without a known version is warned about, not refused (CR-020); a store without `complete` is refused by `open_pvalue_store` (`IncompletePValueStore`); a complete store is written again only with `overwrite`, an interrupted one always.

**Staged runs (CR-021).** A run with `staged.zarr` (C26) coded with a staged calibration (format 3: a mapping per stage) also holds `anomaly_staged` and `ceiling_staged`, `(stage, time, y, x)` uint8, chunks `(1, 1, Y, X)`, packed as above, each stage coded with its own mapping (`Calibration.codes_stage`), written for the anchors `t_lo` .. `staged_t_hi`, and `stage` `(stage,)` int16 (1 .. H - 1); attrs `stages`, `staged_t_hi`, `staged_rule` (copied from `staged.zarr`), and `calibration.n_null_by_stage` (stages 1 .. H - 1). A calibration made under another `staged_rule`, or with other stages, than the run's is refused (`CalibrationMismatch`); a calibration without stages codes the final stage only, with a warning, and the store is that of an unstaged run. Nothing is overwritten as a pyramid fills: every stage keeps its code. `PValueStore.latest(t, name)` gives the current view of anchor t: the final code where it exists, else the code of the highest stage present, and that stage (H for the final code, 0 for none).

**Calibration file format 3 (CR-021, decision D3).** One file per kind, as format 2, with `null` (the final stage) and `null_s1` .. `null_s{H-1}`; a ceiling calibration's `lookup` is `(stages, classes, 256)` with the final stage last; meta `stages` (1 .. H), `n_null_by_stage`, `staged_rule`. Format 2 files still load and code the final stage only. `Calibration.estimate(..., stages=, staged_rule=)` builds one, the null of stage s from the stage s `anomaly_score` of staged panel runs wherever it is finite (`ponzi.calibration.staged_inputs`, which also refuses runs of different staged rules or config hashes), each stage's lookup as the final one's; the final mapping is the plain calibration of the final scores, on the bytes. `ponzi-models calibrate-staged` builds the plain and the ceiling one from the staged panel runs of `ponzi-models null-runs --staged` (CR-051); `ponzi-models calibrate` writes format 2. `provenance.n_null_by_stage` is keyed as the meta's, 1 .. H.
