# PONZI: rules for every repository

- Do not commit, tag or push unless the owner asks; leave changes in the working tree for review.
- HPC: ask before any access and before every non-dry-run `sbatch` or `rsync`. How batches are rendered, approved and submitted is in `../docs/guides/hpc.md`.
- Prose style: no em-dashes anywhere.
